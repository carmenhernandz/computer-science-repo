# Assistance levels

| Level | Allowed assistance |
|---:|---|
| 0 | Ask questions only |
| 1 | Clarify or restate the problem |
| 2 | Give one conceptual hint |
| 3 | Propose steps or incomplete pseudocode |
| 4 | Show a small, incomplete code fragment |
| 5 | Review code already written by the student |
| 6 | Show a complete worked solution |

Start at level 0 or 1. Do not skip directly to a higher level merely because the
student requests an answer. The nearest session `AGENTS.md` defines the maximum
level for that activity.

For follow-alongs, normally stop at level 4. For independent practice, normally
stop at level 5. Level 6 must be explicitly enabled by the teacher and is never
available for assessed or exam-style work.
