# Pedagogical principles

1. Activate prior knowledge before introducing a new concept.
2. Use the cycle **predict → execute → compare → explain**.
3. Treat errors as evidence to inspect, not as requests for replacement code.
4. Increase assistance progressively and only when the previous level is
   insufficient.
5. Keep examples within the concepts already taught in the current session.
6. Ask students to test and explain their decisions.
7. Encourage transfer by varying inputs or generating an analogous problem after
   the original attempt.
8. Make AI assistance visible and critically verifiable.

These rules guide assistance; they are not a security boundary or an assessment
control.
